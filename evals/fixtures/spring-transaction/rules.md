# 预留库存契约

初始库存 10。预留数量必须为正整数且不超过当前可用库存；成功时扣减库存并保存订单预留数量。订单号唯一，重复订单应失败，不能再次扣减库存或覆盖原预留记录。库存不足和非法数量均不得修改数据库。

库存扣减与预留写入属于同一事务。测试通过 Spring 代理调用服务，并在服务事务结束后读取真实数据库；测试方法不加事务，禁止 mock JDBC 或事务管理器。

此 fixture 使用 H2 验证 Spring 事务代理、提交与回滚及数据库状态断言，不证明 MySQL/PostgreSQL 方言、锁、隔离级别或生产迁移兼容性。依赖版本用于重现 Java 8 场景，不作为新项目选型建议。

在隔离目录运行 `mvn test`。错误变体只在临时副本移除 ReservationService.reserve 的 @Transactional：重复订单回滚与代理检查必须失败。不得在业务项目制造此变体。
