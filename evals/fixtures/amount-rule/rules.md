# 金额申请 fixture

隔离纯 Java 模型，用于已有弱断言和金额边界场景。验证范围不含数据库、Spring 或 CI。

已确认规则：金额非空、大于 0、不超过当前剩余额度；金额以分为最小单位，不做隐式舍入。成功新增一次申请并扣减相同额度；拒绝不得新增申请或扣减额度。额度可以为 0。

ApplicationService.java 是当前实现，ApplicationServiceTest.java 是已有测试。已有测试只观察零金额会抛异常。评估时将本目录复制到临时项目，使用现有 JUnit 4.13 或项目兼容设施，先评估覆盖，再补强原测试；无需迁移框架。

测试可使用额度 100.00 下的 -0.01、0、0.01、99.99、100.00、100.01，以及额度为 0 和连续合法申请。拒绝断言需观察申请数和剩余额度。

验证断言效果时，仅在独立副本中制造边界比较符或拒绝前写入的错误变体；正确实现应通过，错误变体应失败。保留每次命令和退出码。SQL/事务场景另行验证。
